# Check Links – releases

Releases of the **Check Links** Revit add-in (I.H BIM Tools). This repository holds no source code, only the files the add-in downloads to update itself.

**Download the setup (always the newest version):**
https://github.com/ibrahimhassansm-lgtm/CheckLinks-releases/raw/main/CheckLinks_Setup.exe

Current version: **1.11.0**

Once installed, Check Links updates itself: about 20 s after Revit starts (and every few hours while it runs) it checks `latest.txt` here, downloads the new version and uses it at the next click.
